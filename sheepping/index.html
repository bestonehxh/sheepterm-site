Source & readmeRelease notes

Many hosts, one table. IPv4 and IPv6, by address or hostname, with live status, latency and success rate. Latency and loss are colour-coded so the bad one stands out.

Features

What it does

Loss and failures stand out

Address or name, IPv4 or IPv6, one per line. Latency turns yellow or red as it climbs, and a host that drops packets shows its success rate.

A log for every host

Select a host to see every packet with its timestamp and latency. Copy it, or save it as CSV.

Also

  • Per-host logs and CSV Every packet is logged with a timestamp. Copy a host's log, save it as CSV, or copy the whole table as CSV.
  • Tune it live A slider sets the ping interval from 0.5 to 30 seconds and another sets the reply timeout. Changes apply immediately to all active hosts and are saved as the default.

Install

Get started in a minute

macOS

  1. Unzip the download and drag SheepPing.app into Applications.
  2. The build is not notarized. On first launch, right-click the app, choose Open, then confirm.
  3. Or run once in Terminal: xattr -dr com.apple.quarantine /Applications/SheepPing.app
  4. Requires macOS 26.4 (Tahoe) or later · Apple Silicon.
