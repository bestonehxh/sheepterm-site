Features

What it does

Highlighting that knows your vendor

Interfaces, VLANs, addresses, MACs and error counters, coloured the way each platform prints them. Detected from the stream; device colours are never overridden.

Families it knows

Cisco IOS / IOS-XE / NX-OSAruba CXArubaOSHuawei VRPH3C / HPE ComwareJuniper JunosPalo Alto PAN-OSFortinet FortiOSCheck Point GaiaLinux

Device web UIs, in a tab

Open a switch or firewall’s web page next to its console, in panes like any session.

  • Self-signed certificate? Trust it once, like an SSH host key.
  • Fill Login fills the saved login only when you click the key.
  • WebKit on Mac, WebView2 on Windows. No bundled browser engine.

Ask AI about the output

Ask Claude or ChatGPT why a port is down or what a log line means, using the subscription you already have.

  • Passwords, keys and community strings are removed before anything is sent.
  • It never runs a command. Suggestions are yours to copy or paste.
  • Off until you install and sign in to the vendor’s own CLI. On Windows, Codex runs in a restricted AppContainer.

Your hosts on every Mac and PC

Sign in with Google and your hosts, groups, credentials, snippets and settings follow you.

  • Encrypted with your passphrase before upload.
  • Stored in a private app folder in your own Drive.
  • Per-record merge; off until you sign in.

Real MAC and ARP on macOS 27

macOS 27 hides MAC addresses from self-signed apps. SheepTerm shows the real ones again, in a local tab and in View ▸ Network Info. Windows has the same window.

Readable themes, your font

Six terminal themes, bundled DejaVu Sans Mono, Liberation Mono and Fira Mono, and Liquid Glass or solid chrome.

Install

Get started in a minute

macOS

  1. Unzip the download and drag SheepTerm.app into Applications.
  2. The build is not notarized. On first launch, right-click the app, choose Open, then confirm.
  3. Or run once in Terminal: xattr -dr com.apple.quarantine /Applications/SheepTerm.app
  4. Requires macOS 26.4 (Tahoe) or later · Apple Silicon.

Windows

  1. SheepTerm for Windows is a portable zip. Unzip it into a folder of your own, not Downloads.
  2. Run SheepTerm.exe. If SmartScreen appears, choose More info, then Run anyway.
  3. Requires Windows 10 or 11, x64.
  4. Your data stays in the Data folder beside the exe. Updates are built in.
