Features

Everything you connect to, in one place

Servers, switches, routers, firewalls, containers and boards on a serial cable.

Highlighting

Output you can read at a glance

Interfaces, VLANs, addresses, MACs and error counters, coloured the way each platform prints them.

  • Detected from the stream — or pick the family per host
  • Device colours are never overridden
  • Non-zero error and drop counters stand out

Workspace

Nine devices in one tab

Split any tab up to 3 × 3, and file hosts the way your network is built.

  • Drag a host onto a pane edge — it opens on that side
  • Groups inside groups, up to four levels, with icons and colours
  • Every pane can go through a jump server
File transfer

TFTP, SFTP, SCP and FTP built in

Let a switch pull firmware from your laptop, or browse a device's files over its SSH session.

  • Servers start off and stop by themselves after 10 idle minutes
  • The copy command for your device, ready to paste
  • Uploads never overwrite a file
Ping

Watch it come back while you reload

A Ping tab splits next to the console: many hosts, a live graph, and a badge that follows the latest packet.

  • IPs, names or ranges like 10.10.1.0/29
  • OK, Slow over 100 ms, Fail at once
  • Per-host packet log, saved as CSV
AI panel

Ask why the port is down

Claude, ChatGPT or Gemini read the output with the subscription you already have.

  • Passwords, keys and community strings removed before sending
  • It never runs a command
  • Off until you install and sign in to the vendor's CLI
Sync

Your hosts on every Mac and PC

Sign in with Google: hosts, groups, credentials, snippets and settings follow you — encrypted before they leave.

  • Your passphrase, end-to-end encryption
  • A private app folder in your own Drive
  • Off until you sign in

Install on Mac

  1. Open the disk image and drag SheepTerm onto Applications.
  2. Signed with Developer ID and notarized by Apple — it opens normally.
  3. Later: SheepTerm ▸ Check for Updates…

Install on Windows

  1. Unzip into a folder of your own, not Downloads.
  2. Run SheepTerm.exe. If SmartScreen appears: More info ▸ Run anyway. Your data stays in the Data folder beside the exe.
  3. Later: Help ▸ Check for Updates…

Install on Linux

  1. Debian / Ubuntu (.deb): sudo apt install ./SheepTerm-*-linux-*.deb
  2. Fedora / RHEL (.rpm): sudo dnf install ./SheepTerm-*-linux-*.rpm
  3. AppImage / .tar.gz: Right-click, open Properties → Permissions, and enable Allow executing file as program (or chmod +x SheepTerm-*.AppImage). Keep any existing Data folder beside the AppImage or binary.
  4. Later: Help ▸ Check for Updates… (updates and restarts in-app).
