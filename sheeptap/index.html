Source & readmeRelease notes

One card per interface. Sits in the menu bar. Click it for one card per active interface, sorted Wi-Fi, Ethernet, VPN, each with IP, subnet mask, gateway, DNS servers and MAC. Wi-Fi cards show the SSID. Check for Updates and Quit sit at the bottom.

Features

What it does

One card per interface

Wi-Fi, Ethernet and VPN, each with IP, subnet mask, gateway, DNS servers and MAC. Wi-Fi cards show the SSID.

Click to copy

Click an address and it goes to the clipboard, with a Copied flash so you know it worked. On a Wi-Fi card, More opens Security, BSSID, Channel, Country, RSSI, Noise, Tx Rate, PHY, MCS and NSS.

Also

  • Quiet and private No network requests, no analytics, no third-party dependencies, and it is fully sandboxed. It updates live from system notifications and costs almost nothing while the menu is closed. Launch at login is set up on first run.

Install

Get started in a minute

macOS

  1. Unzip the download and drag SheepTap.app into Applications.
  2. The build is not notarized. On first launch, right-click the app, choose Open, then confirm.
  3. Or run once in Terminal: xattr -dr com.apple.quarantine /Applications/SheepTap.app
  4. Requires macOS 26.4 (Tahoe) or later · Apple Silicon.
