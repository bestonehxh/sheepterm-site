Features

What it does

Show output you can read

Addresses, MACs, VLANs and up/down states are coloured the way SheepTerm shows them, so a pasted command output reads at a glance. The vendor is detected from the content.

Logs that point at the problem

Errors, err-disable states and down links stand out, so you can read a switch log instead of searching for what went wrong.

Also

  • Highlighting for 28 languages A pure-Swift highlighter colours a 1 MB file in milliseconds, and a keystroke re-colours only the lines it touches. Network config mode detects the vendor from the content.
  • Compare mode Side-by-side diff of two tabs, or a tab and a file. Line-level and word-level changes, moved-line detection, live update as you type, and changed blocks can be transferred between the panes.
  • Multi-cursor and folding Add the next occurrence with ⌘D, or select every one at once. Fold brace blocks from the gutter, and the folds are remembered per document.
  • MAC address conversion Convert a selected MAC between Cisco dotted, colon, hyphen, plain and Aruba formats without leaving the editor.
  • Log highlighting Timestamps dim, errors and counters stand out. Open a switch log and read it instead of searching for the problem.

Install

Get started in a minute

macOS

  1. Unzip the download and drag SheepText.app into Applications.
  2. The build is not notarized. On first launch, right-click the app, choose Open, then confirm.
  3. Or run once in Terminal: xattr -dr com.apple.quarantine /Applications/SheepText.app
  4. Requires macOS 26.4 (Tahoe) or later · Apple Silicon.
